# TernQuill

A macOS terminal built around an input bar: you type commands into a real editor at the bottom, with completion, command blocks, split panes and broadcast, Obsidian notes, and AI agents (Claude Code and others) right next to your terminal.

TernQuill is in **beta**. This repository is where to **report bugs and suggest features**. The app's code isn't here.

## Report a bug or suggest a feature

[Open an issue](https://github.com/TernQuill/ternquill/issues/new/choose) and pick **Bug report** or **Feature request**.

Before you write, check the [open issues](https://github.com/TernQuill/ternquill/issues). Someone may have reported it already; a 👍 on that issue helps us see what matters most.

Useful in a bug report:
- **TernQuill version**: shown at the top right of the window (e.g. `v0.8.6`).
- **macOS version**: Apple menu → About This Mac.
- What you did, what happened and what you expected; a screenshot if it's something you can see.

Please don't post anything private: no passwords, tokens, internal host names or customer data from your terminal.

## Requirements

A Mac with Apple silicon and macOS 13 Ventura or later.
